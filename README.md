# Mis Hábitos ✅

Web app para llevar registro de hábitos diarios, pensada para instalarse en la pantalla de inicio del iPhone.

## Funciones
- **Hoy**: marca hábitos como hechos o suma cantidades (vasos, minutos, páginas). Puedes registrar días pasados.
- **Progreso**: racha actual, mejor racha, % de los últimos 30 días y calendario de 16 semanas.
- **Hábitos**: crear, editar, ordenar y eliminar (ícono, color, días y hora).
- **Recordatorios**: exporta un archivo `.ics` que agrega tus hábitos al Calendario del iPhone con aviso.
- **Respaldo**: descarga y restaura tus datos en JSON.

Los datos se guardan solo en tu teléfono (almacenamiento local del navegador).

## Instalar en el iPhone
1. Abre la página de GitHub Pages en **Safari**.
2. Toca **Compartir → Agregar a pantalla de inicio**.

## Archivos
- `index.html` — toda la app
- `manifest.json`, `icon-*.png` — ícono y configuración de app
- `sw.js` — permite abrirla sin internet
